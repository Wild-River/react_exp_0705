# MyShop 管理画面

![管理画面のスクリーンショット](screenshot.webp)

ECショップの運営者・店舗担当者向けの**管理画面ダッシュボード**です。サイドバーとヘッダーで構成した画面に、商品点数・合計在庫・在庫切れ件数を集計した統計カードと、在庫状況がひと目でわかる商品一覧を表示します。React学習の最初のプロジェクトとして、コンポーネント設計とpropsによるデータの受け渡しに絞って静的サイトとして構築しました。

- **公開URL**：https://react-exp-0705-seven.vercel.app/
  - ログインは不要です

---

## 主な機能

### 統計カード

- 商品データから**商品点数・合計在庫・在庫切れ件数**を計算して表示
- 値は固定値ではなく、商品データの配列から `length` / `reduce` / `filter` で算出

### 商品一覧

- 商品ごとにカードで一覧表示し、カテゴリ・価格・在庫状況を表示
- 在庫数に応じてバッジの表示を切り替え（在庫あり／残りわずか（5個未満）／在庫切れ）
- 価格は `toLocaleString()` で3桁区切りに整形
- 一覧の見出しに商品件数を表示

### 画面レイアウト

- サイドバー（ダッシュボード／商品／設定）とヘッダー（商品追加ボタン）による管理画面らしい構成
- 検索バーや編集・削除ボタンなど、次のステップで機能を載せるためのUIを先に配置

### ディレクトリ構成

```
.
├── src/
│   ├── App.jsx                 # 商品データの定義、統計値の計算、画面全体のレイアウト
│   ├── components/
│   │   ├── Sidebar.jsx         # サイドバー（メニューを配列で定義してmapで表示）
│   │   ├── Header.jsx          # ヘッダー（ショップ名・商品追加ボタン）
│   │   ├── StatCard.jsx        # 統計カード
│   │   ├── PageTitle.jsx       # 見出しと件数
│   │   ├── Toolbar.jsx         # 検索バーなどを並べる枠（childrenで受け取る）
│   │   ├── SearchBar.jsx       # 検索入力欄
│   │   ├── ProductCard.jsx     # 商品1件ぶんのカード
│   │   ├── CategoryTag.jsx     # カテゴリのタグ
│   │   ├── PriceTag.jsx        # 価格表示
│   │   ├── StatusBadge.jsx     # 在庫数に応じた在庫状況バッジ
│   │   ├── Button.jsx          # ボタン（variantで見た目を切り替え）
│   │   └── Divider.jsx         # 区切り線
│   └── index.css               # 全体の基本スタイル
└── public/
```

各コンポーネントは同名の `*.module.css` とセットで管理しています。

## データ設計

商品データは `App.jsx` に配列として定義しています。

| 項目       | 内容                                   |
| ---------- | -------------------------------------- |
| `id`       | 商品ID。`map` で表示するときの `key`   |
| `name`     | 商品名                                 |
| `price`    | 価格（円）                             |
| `stock`    | 在庫数。統計値とバッジの判定に使う     |
| `category` | カテゴリ（アパレル／雑貨など）         |

## 工夫した点

### コンポーネントの分割

- 画面を Sidebar・Header・StatCard・ProductCard・CategoryTag・PriceTag・StatusBadge・Button などの小さな単位に分け、1つのコンポーネントが1つの役割だけを持つようにしました。
- ProductCard は、CategoryTag・PriceTag・StatusBadge・Button を組み合わせて作っています。部品を組み合わせる形にしたことで、価格の表示形式やバッジの判定を変えたいときに、該当するコンポーネントだけを直せば済みます。
- Toolbar は中身を `children` で受け取る形にし、検索バー以外の部品（絞り込みや並べ替えなど）も後から差し込めるようにしています。

### データと表示の分離

- 商品データやサイドバーのメニューは配列で定義し、`map` で表示しています。項目を増やすときは配列に1行足すだけで済みます。
- 統計カードの数値は商品データから計算しているため、データを変えれば表示も自動的に合います。
- 在庫状況の判定ロジックは StatusBadge にまとめ、在庫数を渡すだけでラベルと色が決まるようにしました。

### スタイルの管理

- CSS Modules を使い、コンポーネントごとにスタイルのスコープを閉じることで、クラス名の衝突を防ぎました。
- Button は `variant`（primary／danger）を受け取り、同じコンポーネントで見た目を切り替えています。
